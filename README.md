# Programming Practice

A curated collection of early programming exercises and data-structure implementations.

## Collections

- `cs136-c` — C implementations of a binary search tree, circular array, deque, priority queue, sequence, trie, and linked-list/array exercises
- `java` — selected Java language and object-oriented programming practice
- `python` — selected Python exercises and notes with executable examples
- `cs240-cpp` — C++ exercises for kd-tree partitioning and threshold reporting in a heap-ordered tree

Generated binaries, IDE metadata, third-party packages, lecture slides, exams, and official solutions are excluded.
